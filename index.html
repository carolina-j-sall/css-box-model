Display

display: block is below. Block element: an element that is formatted as a block and takes up the entire width of the viewport. Each block elements starts on a new line.

display: block;

display: inline is below. Inline element: an element that creates content on the same line as the previous element. It does not start on a new line and it only takes up the width required to fit the content.

display: inline;
display: inline;

display: inline-block is below. Inline-block element: an element that combines the properties of both block and inline elements. The content does not start a new row, but you can apply sizing properties to the element.

display: inline-block;
display: inline-block;
